# Development Roadmap

## Phase 1 — MVP (implemented foundation)
Authentication; profiles; parent/child profiles; awareness portal; demonstration screening-support; developmental milestone tracker; resource library; NeuroGuide AI shell; professional directory; appointment requests; parent dashboard; admin-ready API; English/Urdu/Roman Urdu presentation foundation.

## Phase 1.1 — Productionization
PostgreSQL, migrations, MFA/email verification, full RBAC/permissions, consent versioning, CSRF hardening, rate limiting, real CMS, professional verification workflow, file upload security, notification worker, structured audit viewer, full Urdu content governance, automated accessibility tests.

## Phase 2
Therapy tracker; sensory profile; behavior diary; educator portal; IEP assistant; moderated community; events; courses/certification; AAC-inspired communication boards; visual schedules.

## Phase 3
Explainable recommendation engine; governed research portal; advanced privacy-preserving analytics; teleconsultation integration; mobile apps; institutional dashboards.

## Clinical/legal gate before public launch
1. Clinical governance board and content approval process.
2. Screening instrument licensing/copyright review and validated scoring implementation.
3. Privacy impact assessment and child-safeguarding controls for target jurisdictions.
4. Penetration test, threat model, backup/restore test and incident-response plan.
5. Accessibility audit against WCAG 2.2 AA.
